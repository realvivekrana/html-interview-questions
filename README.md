## 📌 About This Repository

This repository contains HTML interview preparation material combined with practical HTML examples.

The questions cover fundamental HTML concepts, semantic elements, lists, forms, attributes, multimedia, browser tools, and basic web concepts such as DNS, IP addresses, and SEO.

The purpose is to revise important concepts, practice HTML syntax, and prepare for frontend developer interviews.

## 🚀 How to Run the Examples

These examples use plain HTML, so no package installation is required.

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to the required day folder.
4. Open the relevant `.html` file in a browser.
5. Alternatively, use the VS Code Live Server extension.

Keep supporting images in their original folders so that relative paths continue to work.
