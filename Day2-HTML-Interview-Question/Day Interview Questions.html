Q.22 Difference between block and inline?

Answer-->

         
Block Elements

         *Take up the full width available (like a block).
         *Always start on a new line.
         *You can set width, height, margin, and padding freely.

     Examples: div tag,paragraph tag,h1 tag-h6 tag,section,article etc.



    
Inline Elements

     *Take up only as much width as their content.
     *Do not start on a new line.
     *You can set horizontal margins and padding, but not width/height.
     Examples: span tag,strong tag,em tag,img tag etc.

Q.25 Difference between HTML tags and elements?

HTML Element
